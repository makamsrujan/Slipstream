# Slipstream

This repository contains a polished portfolio-style landing page inspired by the live showcase at https://slipstream-sandy.vercel.app and the project profile associated with the name "Slipstream".

## What is included
- Responsive one-page portfolio layout
- Modern dark theme and hero section
- About, stack, selected work, and contact sections
- Lightweight Vite setup for easy local running and Vercel deployment

## Run locally
```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Build for production
```bash
npm run build
```

## Deploy on Vercel
1. Push this repository to GitHub.
2. Import the repo in Vercel.
3. Use the default settings; Vercel will detect the Vite app automatically.
